# TG Content Analyzer — автоматическая классификация контента Телеграм-каналов

Инструмент для автоматизированного контент-анализа Телеграм-каналов: определяет **тип** (7 категорий) и **формат** (9 категорий) каждой публикации, строит таблицы частот и соотношений.

Разработан в рамках исследовательской работы про типы и форматы контента в Телеграм-каналах тематической подборки «мода и красота».

---

## Что делает программа

- Случайно отбирает N публикаций с каждого канала за каждый месяц анализируемого периода (стратифицированная выборка)
- Определяет **формат** каждого поста автоматически по метаданным Телеграм API (текст, фото, видео, кружок и т.д.)
- Определяет **тип** контента по принципу доминирующей функции — в гибридном режиме: сначала словарный поиск, при низкой уверенности подключается языковая модель
- Анализирует медиафайлы (изображения, видео, кружки) через компьютерное зрение, расшифровывает аудио
- Строит итоговый Excel-отчёт с 14 аналитическими листами: частоты типов и форматов, таблицы сопряжённости, сравнение сегментов

## Типология контента

### Типы (7 категорий)

| Код | Тип | Функция |
|-----|-----|---------|
| 1 | Информационный | Передача сведений без побуждения к действию |
| 2 | Образовательный | Обучение, формирование экспертного статуса |
| 3 | Анонсовый | Создание ожидания будущего события |
| 4 | Продающий | Стимулирование покупки |
| 5 | Вовлекающий | Получение обратной связи, диалог |
| 6 | Развлекательный | Эмоциональный фон, «очеловечивание» бренда |
| 7 | Имиджево-вдохновляющий | Трансляция ценностей и философии бренда |

### Форматы (9 категорий)

| Код | Формат |
|-----|--------|
| 1 | Текстовый пост |
| 2 | Текстовый пост с фото |
| 3 | Текстовый пост с видео |
| 4 | Фото без текста |
| 5 | Видео без текста |
| 6 | Кружок |
| 7 | Голосовое сообщение |
| 8 | Смешанный формат |
| 9 | Иной формат (опросы, GIF, стикеры) |

## Требования

- Python 3.10+
- [Ollama](https://ollama.com) — для локального запуска языковых моделей
- Модели Ollama: `qwen2.5:7b` (текст) и `qwen2.5vl:7b` (изображения/видео)
- Учётные данные Telegram API (API ID и API Hash)

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/your-username/tg-content-analyzer.git
cd tg-content-analyzer
```

### 2. Создать виртуальное окружение и установить зависимости

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Установить Ollama и скачать модели

Скачайте и установите Ollama с [ollama.com](https://ollama.com), затем:

```bash
ollama pull qwen2.5:7b
ollama pull qwen2.5vl:7b
```

Проверьте что Ollama запущена:

```bash
ollama list
```

### 4. Получить Telegram API credentials

1. Перейдите на [my.telegram.org](https://my.telegram.org)
2. Войдите в свой аккаунт
3. Перейдите в раздел **API development tools**
4. Создайте приложение — получите `API ID` и `API Hash`

### 5. Настроить переменные окружения

Скопируйте файл примера и заполните своими данными:

```bash
cp .env.example .env
```

Откройте `.env` и заполните:

```
API_ID=12345678
API_HASH=abcdef1234567890abcdef1234567890
PHONE=+79001234567
SESSION_NAME=tg_analyzer_session
```

> **Важно:** файл `.env` добавлен в `.gitignore` и никогда не попадёт в репозиторий. Никому не передавайте свои API-ключи.

### 6. Подготовить список каналов

Скопируйте файл примера:

```bash
cp channels_example.csv channels.csv
```

Откройте `channels.csv` и добавьте каналы в формате:

```csv
channel_url,segment
https://t.me/название_канала,beauty
https://t.me/название_канала,fashion
```

Сегмент может быть любым — он используется для группировки в отчёте.

## Запуск

### Базовый запуск

```bash
python main.py \
  --channels channels.csv \
  --start-date 2025-11-01 \
  --end-date 2026-04-30 \
  --posts-per-month 10 \
  --seed 42 \
  --output result.xlsx
```

### Все параметры

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `--channels` | — | Путь к CSV-файлу со списком каналов |
| `--start-date` | — | Начало периода (YYYY-MM-DD) |
| `--end-date` | — | Конец периода (YYYY-MM-DD) |
| `--posts-per-month` | 2 | Постов с канала в месяц |
| `--seed` | 42 | Семя для воспроизводимости |
| `--output` | result.xlsx | Имя выходного файла |
| `--type-classification-mode` | hybrid | `rules` / `llm` / `hybrid` |
| `--manual-review-threshold` | 0.65 | Порог уверенности (0.1–0.9) |
| `--enable-media-download` | false | Скачивать медиафайлы |
| `--enable-ocr` | false | OCR изображений |
| `--enable-audio-transcription` | false | Расшифровка аудио |

### Режимы классификации типов

- `rules` — только словари и правила, быстро, без Ollama
- `llm` — только языковая модель, медленнее, точнее
- `hybrid` — сначала правила, при низкой уверенности подключается LLM (рекомендуется)

### Пример с полным анализом медиа

```bash
python main.py \
  --channels channels.csv \
  --start-date 2025-11-01 \
  --end-date 2026-04-30 \
  --posts-per-month 10 \
  --type-classification-mode hybrid \
  --manual-review-threshold 0.61 \
  --enable-media-download true \
  --enable-ocr true \
  --enable-audio-transcription true \
  --output result.xlsx
```

При первом запуске программа попросит ввести код подтверждения из Telegram:

```
Введите код подтверждения: 12345
```

После успешной авторизации создаётся файл сессии (`.session`) — повторная авторизация не нужна.

> **Важно:** файлы сессии (`*.session`) добавлены в `.gitignore`. Никогда не публикуйте их.

## Структура выходного файла

Программа создаёт Excel-файл с 14 листами:

| Лист | Содержание |
|------|-----------|
| `posts_raw` | Все публикации с кодами типа, формата, метаданными |
| `type_stats_total` | Частоты типов по всему массиву |
| `format_stats_total` | Частоты форматов по всему массиву |
| `combo_stats_total` | Частоты комбинаций тип+формат |
| `type_stats_by_segment` | Частоты типов по сегментам |
| `format_stats_by_segment` | Частоты форматов по сегментам |
| `combo_stats_by_segment` | Комбинации по сегментам |
| `segment_comparison` | Сравнение сегментов |
| и др. | Дополнительные аналитические срезы |

## Ручная верификация

Публикации с уверенностью ниже порога (`--manual-review-threshold`) сохраняются в отдельный файл `*_manual_review.xlsx`. После ручной правки запустите:

```bash
python main.py \
  --channels channels.csv \
  --start-date 2025-11-01 \
  --end-date 2026-04-30 \
  --manual-review result_manual_review.xlsx \
  --output result_final.xlsx
```

## Автоматическое исправление противоречий

После получения результатов можно запустить скрипт автоматической проверки на соответствие кодификатору:

```bash
python auto_fix.py \
  --input result.xlsx \
  --output result_fixed.xlsx
```

Скрипт исправляет типичные противоречия: объявления победителей конкурса классифицированные как вовлекающий, мем-форматы без развлекательного типа и другие.

## Возможные проблемы

**Ошибка `API_ID не задан`** — проверьте что файл `.env` создан и заполнен.

**Ошибка подключения к Ollama** — убедитесь что Ollama запущена (`ollama serve`) и модели скачаны (`ollama list`).

**Ошибка авторизации Telegram** — проверьте правильность номера телефона в `.env`. Номер должен быть в формате `+79001234567`.

**Медленная работа** — при большом числе каналов и включённом анализе медиа процесс может занимать несколько часов. Рекомендуется запускать в ночное время или использовать режим `--type-classification-mode rules` для быстрой первичной разметки.
